# 19. 개발 가드레일

루트 [AGENTS.md](../AGENTS.md)가 공통 개발 지침입니다. 변경 전에 관련 계약과 실제 코드를 읽고 필요한 최소 범위의 회귀를 실행합니다. 구현과 예제·문서를 같은 변경에 맞춥니다.

인증·실수신자·운영 DB·업무 Task는 개발 fixture가 아닙니다. 독립 합성 runtime으로 서비스·migration·SMTP를 확인하고 실제 모델이 필요한 경우 명시적 `--live` 경로를 선택합니다. 무관한 서비스·전역 CLI 설정·호스트 보안 정책을 변경해 테스트를 통과시키지 않습니다.

외부 의존이 실패하면 원인과 재개 조건을 기록합니다. 동일 실패를 반복하거나 도구 종료 코드·모델 자기보고만으로 완료를 선언하지 않습니다. 사용자 입력·권한·네트워크·버전 등의 전제가 실제 바뀌었을 때 다시 검증합니다.

검증된 SMTP 원문·receipt·Task 버전·archive의 불변성과 불확실 전송 정책을 유지합니다. 자원 삭제는 기존 제품 계약의 비활성화를 따르며 물리 삭제·복원은 명시적인 운영 작업으로 구분합니다. 공개 증거에는 개인정보와 원래 운영 지시문을 넣지 않습니다.
