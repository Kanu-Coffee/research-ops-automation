# 02. 범위와 원칙

v1.0.0은 단일 Linux 호스트의 조사·이메일 실행 도구입니다. Task 관리, native CLI 두 단계 실행, 예약, SMTP 전달, 사용자 권한과 감사·백업을 제공합니다.

- 작업 내용은 사용자 문서가 정하고 앱은 구조·안전·무결성을 검증합니다.
- 실제 주소·비밀번호는 앱의 보호된 전달 영역에만 둡니다.
- 검증을 통과한 원문은 재작성하지 않습니다. 실패 응답을 느슨한 파싱으로 복구하지 않습니다.
- 자료·이력은 유지하며 삭제 기능은 기본적으로 catalog 비활성화입니다.
- 개발 테스트에는 합성 자료·임시 runtime·SMTP double을 사용합니다.
- 실행 권한과 기능 성공, SMTP 수락과 수신함 도착을 구분합니다.

외부 비신뢰 사용자의 임의 코드 실행, 완전한 OS·네트워크·quota 격리, 고가용성 분산 실행, 임의 connector의 보편적 지원은 제공 범위에 포함되지 않습니다. 세부 제약은 [보안](12_SECURITY.md)과 [릴리스 범위](STATUS.md)를 따릅니다.
