# 01. 제품 개요

ResearchOps는 반복 조사와 이메일 보고를 Task 단위로 자동화합니다. 사용자는 조사 지시문 `task.md`, 메일 규격 `email_spec.md`, 실행·전달 설정을 작성합니다. AI는 Research에서 자료·구조화 결과를 만들고 Compose에서 최종 제목·HTML·plain text와 수신자 그룹 선택을 반환합니다.

앱은 스케줄·버전·실행 큐·파일 안전성·메일 전달 무결성·실제 SMTP·감사를 책임집니다. 결과의 사실성·중요도를 별도 모델로 재평가하거나 읽을 수 있는 record를 조용히 삭제하지 않습니다. 근거 검토와 업무 판단은 Task를 작성하는 사용자의 책임입니다.

주 사용자는 승인된 내부 신뢰 사용자입니다. 관리자는 전체 운영과 계정을 관리하고, 사용자는 본인 자원을 운영하며, 조회자는 지정된 Task 결과를 읽습니다. 기본 예제는 가상 소프트웨어 릴리스 공지입니다. [운영 가이드](PRODUCTION_OPERATIONS.md)에서 실제 사용 흐름을 설명합니다.
